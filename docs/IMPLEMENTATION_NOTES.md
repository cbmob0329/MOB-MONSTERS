## CORE用暫定実装

以下は遊べる状態にするための仮値/仮割当で、後からデータ差し替え前提。

1. **エリアボス割当**
   - 1周目/2周目の全ボスをMOB MONSTERS用としてまだ個別確定していないため、MOB STORYと現行マスターから仮配置。
2. **ボス追加行動確率**
   - 「もう一度行動できることがある」の確率を35%で実装。
3. **Record継承時のLv**
   - 継承RecordはLv1から開始。
4. **MOB SOUL自然ドロップ**
   - 0.03%で仮設定。
5. **戦闘用ステータス成長係数**
   - MOB STORYの計算思想に寄せたCORE用係数。実戦テスト後に調整する。
6. **探索**
   - 未確定なので通常AreaはBATTLE CHECKとして戦闘進行のみ。2周目1F/2Fは戦闘なしで通過。
7. **初期配布**
   - 10体のスターター、SOUL、ドロップ率UPアイテムはテスト用。

## 実装上の境界

MOB STORYとMOB MONSTERSは別のlocalStorageキーを使う。
Astra等で別ゲームを並行制作しても、同じMOB MONSTERSディレクトリ/リポジトリを同時編集しなければ競合しない。
