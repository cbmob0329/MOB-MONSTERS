# MOB MONSTERS v0.2.3 — HOME / PARTY / SOUL

## 導入

ZIP内の `MOB-MONSTERS-v0023-HOME-PRODUCTION` フォルダーの中身を、既存サイトのルートへまとめてコピーしてください。差分パッチではなく、HTML・CSS・JavaScript・UI素材を含むフルファイルです。ビルドは不要です。

ローカル確認は `start_server.bat` または `node tools/preview.cjs` でHTTPサーバーを起動し、ブラウザーで開きます。ファイルを直接開くよりHTTPでの確認を推奨します。

既存セーブは `mob_monsters_core_v001` のキーとversion 1を維持します。同じブラウザー・同じオリジンで置き換えてください。別のURL・ポート・ブラウザーにはlocalStorageが自動で移りません。設定にセーブJSONの書き出し機能を追加しました。

## 変更点

- HOME：既存MOBの王宮背景に10体を配置。奥から控え4、スーパーサブ2、メイン4。軽い待機アニメ、右側5施設、下部HOME・編成・設定。高さ740px以下では全10体が収まる省スペース配置。
- お城：リリスの案内、現在の冒険地点、編成不足時の誘導。闘技場もここから利用できます。
- 冒険：既存のSEASON・戦闘構造を維持し、エリア選択ボタンを追加。ボス戦の敵配列が二重になる既存不具合を修正。戦闘のボタン背景とHP/MPゲージの表示崩れも修正。
- 編成：4/2/4の正方形枠、タップ交換・長押し移動、最大5列の所持一覧、レベル・種族・ランク・属性ソート。配置後は一覧位置とソートを保持。
- 詳細：既存ステータス・パッシブ・耐性・習得技を維持し、編成ボタンと円形ソウルレコードボタンを追加。
- ラボ：ちびリリスから「ソウルを確認」「ソウルフュージョン」のみ。レコード育成は置いていません。
- ソウル：個別トークン単位の5列一覧、並び替え・詳細・戻る。半透明、暗色グラデーション、背面の残像。
- フュージョン：A/B選択のはい・いいえ、実行確認のはい・いいえ・A/B解除、未発見候補のシルエットと???、候補確認、継承する力の選択、合体＋約3秒の光、誕生、編成への確認導線。
- 育成：＋/－、既存REXPを差し引いた必要ポイント、不足時の赤色表示、はい・いいえ、上昇する粒子とレベルアップ表示。Lv70上限。回転演出なし。
- 設定：テストモード、5倍速、アイテム・コイン・ダイヤ・ソウル・SPのMAX。状態保存・OFF時の資源復帰。マスターOFFで各テスト機能もOFF。
- SHOP：既存ドロップ率強化アイテムを購入・使用。どちらもはい・いいえ確認。
- ガチャ：通貨を使わないおためしシールガチャ。シールの所持枚数は保存。

## データ・仮定

213モンスター、30パッシブ、120レコード、固定合成91件、レコード合成20件、10SEASONの元データ `js/data.js` は変更していません。Lv30以上のレコードとMASTER合成レコードだけを継承候補にし、固有パッシブは継承しません。実際に選んだA/Bトークンから候補を判定・消費します。

通常戦闘報酬に、基礎モンスターEXPの70%（四捨五入）の共有ソウルポイントを追加しました。既存のモンスターEXP・育成中レコードREXPも従来通り獲得します。SPの配布量、ショップ価格200/400/600/800 G、MAX数量は調整可能な今回の初期値です。

MAXはテストモード下で保存時に補充します。アイテム999、通貨/SP 9,999,999、ソウルは全213種各10個を基準にしています。OFFで開始前の資源を復元し、テスト中に誕生・育成したモンスターは保持します。ソウルはテスト追加分を除去し、開始前のトークンを戻します。テスト中の合成・育成を取り消すスイッチではありません。

## 素材と差し替え

`js/ui_assets.js` でHOME・ラボ・城・リリス・ちびリリスの画像を変更できます。背景はサイトルートからの相対パス、人物は既存MOB QUEST素材の相対パスです。専用ソウル画像は `soulOverrides` にモンスター名と画像パスを登録できます。

HOME・ラボ背景は同梱。モンスターと技素材は従来のGitHubローダーを使い、GitHub→予備ホスト→同名ローカルファイルの順で読み込みます。画像フォルダーの既存ローカル資産は削除不要です。ネットワークが利用できない場合、未同梱モンスター・技画像にはフォールバック表示が使われます。

参照元：[MOB QUEST](https://github.com/cbmob0329/MOB-QUEST)。`back/king1.png`、`back/maojo3.png`、`play/14.png` を使用。既存コードの `play/11.png` と `back/matrix4.png` は検査時404だったため新UIでは使っていません。リリスとちびリリスは現時点では同じ既存絵をサイズ違いで利用します。専用ちび画像は設定ファイル一箇所で交換できます。

fig / eventfig / wepon / weapon / bogu は使用していません。skill / skill2 は既存の技エフェクトとして継続使用します。
