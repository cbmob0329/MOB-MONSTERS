# v0.3.5 会話・冒険演出と初回草原の調整

## 会話

- オープニングのリリスに、立ち絵と尾付きの明るい吹き出しを追加しました。文字は順に表示し、句読点で間を取ります。
- 文字送り中に本文または「全文表示」をタップすると、そのページの全文を表示します。その後「次へ」で進みます。冒頭のナレーションの1秒待機は維持しています。
- ナレーション、仲間・ロボの獲得、入力案内、最後の冒険案内をリリスの発言と分離しました。ナレーションにリリスの立ち絵は出しません。「・・・・・？」はプレイヤーの反応として表示します。
- 玉座の会話はページ分割。初回依頼の報酬獲得文も独立したナレーションです。玉座とソウルラボの短い挨拶にも文字送りを追加しました。
- 会話の進行保存と、スターター・報酬の重複防止は維持しています。

## 演出

- 出発：ロボ起動、接続表示、光のゲート、移動線、転送完了。
- 帰還：暖色のゲートからロボが着地し、HOMEへ戻ります。探索の「帰還」とAREA 4の出口の両方に対応します。
- ソウルレコード育成：光の輪、エンブレム、育成前後のLv、新習得技の出現演出。
- 戦闘結果：モンスターとアクティブレコードのLv上昇を専用欄に表示します。
- OSの「動きを減らす」設定では文字送りを即時表示にし、大きな移動・拡大演出を抑えます。

## 初回の草原

- 対象は通常草原のAREA 1。最初の戦闘は敵1体、その後は1～2体です。全員Lv3なので平均もLv3になります。
- 初心者用の敵は草原の通常敵のうち最低ランクから選び、フィールド頭上のLvと実際の戦闘Lvを一致させています。
- 同じ探索中は勝利後もこの設定を維持します。勝利して帰還した時、またはAREA 2へ進んだ時に初回支援を完了します。勝てずに帰還・敗北した場合や、途中で再読み込みした場合は支援を残します。
- 洞窟・AREA 2以降・深層は従来のレベル設定です。旧セーブでは未クリアかつ支援完了記録がなければ、同じ支援を適用します。
