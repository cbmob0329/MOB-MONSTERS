# v0.3.6 仲間集め支援と施設の操作配置

- メイン4枠に編成した有効なモンスターが3体未満なら、冒険の通常敵との戦闘は必ず1体です。帰還回数や初回支援の旧完了フラグには依存しません。洞窟の通常敵にも適用します。中ボス・ボスの既存構成は維持します。
- 通常草原のAREA 1は、メインが3体未満なら帰還後も初心者用の最低ランク・Lv3の敵を継続します。洞窟や他AREAのLvは変更しません。
- この支援中の草原AREA 1は、敵HPを通常計算の75%、ATK・MAGを70%、DEF・MNDを80%にし、敵の行動を通常攻撃に限定します。1体でも技・相性で初期スライムが負けるケースがあったためです。支援対象外の敵には適用しません。
- 通常草原ではメインが3体未満、または初回支援中のフィールドの場合にソウル率を20ポイント加算します。Fランクは40%→60%。既存のソウル率アップアイテムと加算し、上限100%、ボスの確定ドロップを維持します。
- オープニングを「より良いソウルのモンスターを育成し」に修正しました。
- リリスとの会話後のナレーション末尾に「最初の冒険はソウルのドロップ率が少しだけ上がっています！たくさん仲間にしましょう！」を追加しました。既存の途中セーブのページ番号をずらさないため末尾への追加です。
- ソウルラボとお城は、ヘッダー・立ち絵／吹き出し・操作ボタンを画面の高さに合わせて配置します。ラボにはソウル確認とフュージョンの直接ボタンも追加しました。

検証：`tests/update936_browser.cjs` で390×844、375×667、320×568のEdgeタッチ環境を確認。全施設ボタンの表示範囲・タップ位置・スクロール位置、ラボからの遷移、ナレーション、旧支援完了後の再支援、パーティー人数別の敵数、抽選値を固定したソウル率加算を検証しました。`update935_browser.cjs`、`smoke.js`、`asset_contract.js`、`ui_runtime_smoke.js` も実行。iPhone実機は未確認です。

`tests/update936_balance.cjs` は表示待ちだけを短縮して実際の戦闘処理を実行します。初期Lv5スライム対支援対象8種のLv3・1体で、それぞれ勝利することを確認しました（全乱数・全操作での勝利保証ではありません）。
