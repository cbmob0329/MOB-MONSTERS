# v0.3.4 テスト用オート戦闘と習得Lv表示

- テストモードの戦闘画面右上にAUTO ON／OFFを追加しました。各戦闘はOFFで開始します。
- ONではMP内で使える習得技を選択します。HPが半分未満の味方がいれば使用可能な回復専用技を優先し、それ以外は威力の高い攻撃技、使用できなければ通常攻撃を選びます。攻撃先は選択中の敵を優先します。
- OFFへの切り替えは予約中の自動行動を取り消します。実行中の行動は最後まで行い、次の味方の行動から手動入力を待ちます。アイテムの自動消費や自動逃走は行いません。
- オート中の戦闘不能時は控えから補充します。従来の交代禁止ルールは維持します。戦闘ログや詳細を開いている間、新しい自動行動は待機します。
- ソウルレコードの育成画面に技名と必要Lvを追加しました。習得済み・今回習得・未習得の状態と、次に習得する技を表示します。選択レコードや育成先Lvを変えると更新されます。

検証：`tests/update934_browser.cjs` でスマホ相当のEdgeにて切り替え、予約取消、実行途中のOFF、手動復帰、控え補充、通常モードでの非表示、習得技の自動使用と勝利、育成プレビューと購入後の状態を確認。既存のsmoke・asset_contract・ui_runtime_smokeも実行しました。iPhone実機は未確認です。
