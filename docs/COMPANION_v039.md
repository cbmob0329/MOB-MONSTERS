# MOB MONSTERS 仲間・戦闘・エディター修正 v039

対象：262体、304技、310ソウルレコード。STORY／PIECEのファイルは変更していません。コミット・push・公開は実施していません。

## 主な変更

- 仲間の6状態耐性がすべてSSだった91体を含め、種族・属性に応じた強弱へ再設定。仲間用パッシブを割り当て、敵専用の追加行動特性は敵側に保存。
- フレイムマジックは低MPの全体魔法、フレイムフラッシュは単体への強めの攻撃＋低率やけど。マカロン・ノータイムはマヒ15%・攻撃強化、ティータイムは味方1体の最大HP25%回復・MP12。データ上の正式名「モブネコマカロン」は変更なし。
- 全技のクールダウンを廃止。MPで使用を管理。304技の説明を整え、レコードの技名から詳細を開けるように変更。実装用の攻撃倍率はゲーム内説明に表示しない。
- 同じレコード内・全技間の完全同一効果を監査し、重複組み合わせを解消。比較は属性・対象・MP・状態異常・補助効果などの実処理フィールドに基づく。
- 編成は「仲間選択→配置先」で配置・交換。所持仲間は削除しない。同枠・解除・取消・保存失敗時の復元を扱う。
- Skill3の単独画像とskill4/v251の座標表を使用。実シートの非均一矩形を切り出し、4フレーム再生の3枚目で命中。前衛とスーパーサブの被弾対象に揺れを表示。既存画像＋canvasのみ。

## エディター

`MOB_MONSTERS_EDITOR_v039.zip` を展開し `index.html` を開く。サーバー不要。モンスター／耐性／技／レコード／融合／パッシブを検索・編集し、差分JSONを書き出す。ゲームの設定画面から検証して導入できる。

ID・保存用の名前は固定。差分は変更前の値を含み、一致しない版には適用しない。全変更が有効な場合だけ適用する。育成セーブとは別キーで保存し、既存の育成値や習得済みレコードを消去しない。固有レコードの構成変更は新規生成に反映され、既存個体の習得履歴は保持される。

自由な説明文は処理の代わりにはならない。ゲームでは独自説明に加えて実際の処理内容を表示。独自効果は要実装として下書き保存できるが、ゲームには導入不可。パッシブは既存の実装済み種類から選択。新しい報酬文・系譜・レコード融合条件の処理追加は別途実装が必要。

モブエーデン、モブコードコドラ、モブパレット、モブネオンキングは参照元に対応する画像指定がなく、エディターでは画像を表示しない。新規画像生成はしていない。
