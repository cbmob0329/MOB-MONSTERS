# v0.3.3 更新内容

## ソウルとソウルラボ

- テストのソウルMAXは各種2個。旧テストデータの余分なテスト産ソウルを整理し、通常プレイで獲得したソウルは残します。通常獲得分が2個を超えていても削除しません。
- ソウル一覧は30個ずつ表示し、画像の重複描画も削減しました。変換一覧は24個ずつ表示し、名前検索に対応します。
- モンスター1体をソウル1個へ変換できます。編成中のモンスターは対象外。レコード・系譜・カセットを引き継ぎます。
- ソウル1個をルビーへ変換できます。交換数は暫定で「1＋ランク順番号×2」（最下位ランクの順番号は0）。確認画面に獲得数を表示し、変換結果を保存します。フュージョン選択中のソウルは変換できません。
- 両方に確認画面、変換演出、獲得結果を追加しました。

## 画面と冒険

- MOB SHOP・ガチャなどの施設が暗い背景レイヤーに隠れる問題を修正しました。画像は同梱ファイルを優先し、外部URLを予備として使います。
- フィールドの敵と戦闘中の敵の頭上に名前・Lvを表示します。接触した敵のLvを戦闘へ引き継ぎます。
- AREA 1～3に洞窟を配置し、進んだAREAに応じた洞窟のLvを使用します。AREA 4はボスです。
- 敵の能力計算はLv120まで対応しました。味方の既存上限Lv99は維持しています。
- 冒険の解放順をシーズン1～8＋クリア後へ合わせました。既存セーブの達成キーと闘技場などが参照する従来データは互換性のため残しています。

## オープニング

添付の「MOB MONSTERS オープニング.txt」を参考に、NEW GAMEでナレーション、リリスとの会話、主人公名、Lv5スライムの命名、ロボ入手と案内を実装しました。ナレーションは表示から1秒後に進められます。進行は保存され、途中再開でスターターを重複付与しません。既存セーブのCONTINUEでは新たに開始しません。

テストモードでは確認付きのスキップを利用できます。リリスの城に会話と8項目のヘルプを追加し、最初の仲間3体追加で3000コイン・10ダイヤを一度だけ受け取れます。その後は草原中ボスへ案内します。
