# v0.3.0 — 下部の正方形パーティー表示と撃破演出

## 変更内容

- 戦闘中の味方の立ち絵列（パーティーA）を撤去しました。左側の正方形一覧もなくし、下部の正方形画像に統一しています。
- 下部パネルの下段にメイン4体を横一列、上段中央に小さめのスーパーサブ2体を配置。名前とHP・MPバーを表示し、行動中の仲間を枠とラベルで示します。
- 正方形画像からの味方詳細、回復対象の選択、敵の対象固定、コマンド入力は維持。味方への全体エフェクトは下部のメイン4体の中央に表示します。控え4体は常時表示しません。
- 敵のHPが0になっても直ちに消さず、短い発光・粒子・「撃破」表示・フェードアウトを経て消えるようにしました。回転や繰り返す点滅はありません。
- 通常攻撃、技、反撃、毒・やけどによる撃破に共通の処理を使用。演出完了後に次の敵の補充へ進み、同じ敵を撃破・報酬対象として重複登録しません。
- 通常敵の撃破演出は約0.62秒、ボスは約0.85秒。戦闘速度設定に追従し、5倍時も最低0.24秒は表示します。「動きを減らす」設定では約0.18秒の簡潔な表示になります。

## 検証

Edgeのスマホ想定画面（320×568、375×667、390×844、430×932）で、画像が正方形であること、下部パネル・敵・コマンドが重ならないことを確認しました。

- メイン4体・スーパーサブ2体、立ち絵列と左側一覧の撤去。
- 味方詳細、回復対象の選択、固定した敵への攻撃。
- 通常の撃破、反撃、毒、やけど、ボス、控え敵の繰り上がり。
- 撃破の重複登録防止、戦闘結果画面への遷移。
- 5倍速度、動きを減らす設定、味方への全体エフェクトの表示位置。
- タイトル・HOME・探索・接敵・逃走・宝箱・ボス報酬・帰還・セーブ再開の回帰確認。
- JavaScript構文、データと素材の既存検査。

テストは `tests/battle_v0030.cjs` と `tests/regression_v0030.cjs`、画面画像は `tests/screenshots/030-*.png` にあります。実機iPhone/AndroidとSafariでは未検証です。
