# MOB MONSTERS 現行仕様

## 1. モンスター

ランクは `F → E → D → C → B → A → S → SS → MOB`。
属性は `無 / 火 / 水 / 雷 / 地 / 風 / 光 / 闇`。
種族は `スライム / ビースト / ネイチャー / アクア / ドラゴン / デーモン / マシン / マテリアル / ヒューマノイド / ボス` の10種。

耐性は属性・状態異常ごとに F～SS。ボスだから一律無効にはしない。SSも完全無効ではない。

## 2. パッシブ

30種からモンスター固有で持つ。

- F～B：1個
- A～SS：2個
- MOB：3個

通常のSOUL FUSION、RECORD FUSION、育成ではパッシブを引き継がない。
クリア後のMOBランク化のみ、本人が持つパッシブと使用SOULが持つパッシブを候補にして3つ選択できる予定。
詳細なMOBランク化仕様は保留。

代表特性：

- メタルボディ：HP少、DEF非常に高い、被ダメージ90%軽減、魔法無効、会心に弱い
- ボスモンスター：AI 1～2回行動。行動後にもう一度動くことがある
- 立ちはだかる強敵：会心率+5%

変身系パッシブは不採用。

## 3. パーティー / 戦闘

MOB STORY準拠。

- MAIN：4体
- SUPER SUB：2体
- SUB：4体
- 合計：10体

SUPER SUBは2～5ターンに1回自動行動。
敵全体攻撃は受けるがダメージ50%。味方の全体回復は通常量。
MAINがダウンしたらSUPER SUB / SUBから入替可能。

戦闘は敵味方まとめてSPD順のターン制。
ステータス表記は `HP / MP / ATK / DEF / SPD / MAG / MND`。
基本会心率3%、会心威力1.5倍。

状態異常もMOB STORY準拠を基本とする。
毒・やけど・マヒ・眠り・ひるみ・混乱などを扱う。
眠りは被弾時70%解除、ひるみは1ターン、味方マヒはアイテム解除を基本とし、敵は自然回復、ボスは早めに回復する。

## 4. レベル / EXP

- モンスター最大Lv：99
- SOUL RECORD最大Lv：70
- 1戦でモンスターEXPとRECORD EXPの両方を得る
- MAIN：100%
- SUPER SUB：70%
- SUB：30%
- 途中からMAINとして戦った個体はその戦闘100%
- SOUL FUSION後のモンスターはLv1
- 育成中に選択したSOUL RECORDへRECORD EXPを入れる

暫定必要EXP式：

- モンスター次Lv：`30 + 8×Lv + 1.6×Lv²`
- Record次Lv：`20 + 5×Lv + 1.2×Lv²`

## 5. SOUL

撃破時にSOULを落とすことがある。イベント/固定入手も可能。
基本ドロップ率の現在値：

- F 40%
- E 30%
- D 20%
- C 12%
- B 6%
- A 2.5%
- S 0.7%
- SS 0.1%
- MOB 0.03%（暫定）

ドロップブーストは**加算**。

- リトルミュージック：+3ポイント
- 名称未定：+7ポイント
- 名称未定：+12ポイント
- 名称未定：+20ポイント

連続使用すると合算される。

## 6. SOUL FUSION

SOULを2つ使う。性別なし。
同SOUL×同SOULは同じモンスター。
異種SOULは固定 / SECRET / 系譜レシピを優先し、それ以外は通常FUSION。
通常FUSIONは親ランク平均+1段階を基本に、既存モンスターから最大3候補を提示する。
通常FUSIONの上限はSS。通常候補からMOBと種族「ボス」は出さない。

正史・系譜を壊さず、存在しない中間モンスターを自動生成しない。

## 7. SOUL RECORD

- Lv1～70
- Lv30：SOUL FUSION時の継承候補
- Lv70：MASTER
- 1体が複数Recordを持てる
- 技の所持/使用数制限なし

1Record=10マイルストーンのデータ構造は維持するが、技5個固定にはしない。
Recordによって技が少なく、STAT・バフ・耐性・補助効果が多い構成も可能。

指定2Recordが両方MASTERの状態でSOUL FUSIONするとRECORD FUSION結果を継承候補に追加できる。

## 8. ストーリー

通常9エリア：

`草原 / 砂漠 / 田舎町 / ネオン街 / 海底 / 部族村 / マグマ / 魔王城 / 読みかけの本`

各エリアは1F～4F。各FにArea1～4。奥ほど敵が強くなる。

### 1周目

- SEASON 1：草原 / 砂漠 / 田舎町
- SEASON 2：ネオン街 / 海底
- SEASON 3：部族村 / マグマ
- SEASON 4：魔王城
- SEASON 5：読みかけの本

1F～2Fを探索し、2F Area4でボス。

### 2周目

- SEASON 6：草原 / 砂漠 / 田舎町
- SEASON 7：ネオン街 / 海底
- SEASON 8：部族村 / マグマ
- SEASON 9：魔王城
- SEASON 10：読みかけの本

2周目も1F、2Fを順番に通る。ただし攻略済み区画なので探索せず進行可能。
3F～4Fを探索し、4F Area4でボス。

SEASON 10クリア後、**薔薇の国**をラストダンジョンとして解放。

## 9. キャンプ / ワープメープル

キャンプでワープメープルを使うとHOMEへ帰還。
HOMEから「冒険再開」で、そのキャンプ地点から再開できる。
探索/キャンプ配置の詳細は今後決定。

## 10. 闘技場

通常は4vs4。
各ランクで3戦勝利すると昇格戦。
昇格戦のみCREW BATTLE 10vs10。
昇格戦で負けても何度でも再挑戦可能。

解放条件：

- F：最初から
- E：Fクリア
- D：Eクリア + SEASON 1クリア
- C：Dクリア + SEASON 2クリア
- B：Cクリア + SEASON 3クリア
- A：Bクリア + SEASON 4クリア
- S：Aクリア + SEASON 5クリア
- SS：Sクリア + SEASON 10クリア
- MOB：SSまで全クリア後に挑戦
